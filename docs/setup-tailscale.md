# 폰에서 접속하기 (Tailscale)

MemoReader 서버는 `127.0.0.1`에서만 열려 있다. 폰은 Tailscale의 `tailscale serve`를 통해서만 접속하며, 이때 Tailscale이 붙여 주는 신원 헤더(로그인 계정)로 인증한다. 별도 비밀번호는 없다.

> 이 문서의 명령은 Tailscale 공식 CLI 기준이며, 이 프로젝트를 만든 PC에는 Tailscale이 없어 실기기에서 검증하지 못했다. 막히면 `tailscale serve --help`로 현재 버전의 옵션을 확인한다.

## 1. 준비 (한 번만)

1. PC와 폰에 Tailscale을 설치하고 **같은 계정**으로 로그인한다.
2. Tailscale 관리 콘솔(https://login.tailscale.com/admin/dns)에서 **MagicDNS**와 **HTTPS Certificates**를 켠다. HTTPS가 있어야 PWA 설치와 공유 메뉴 등록이 된다.

## 2. 서버 공개 (PC)

```bat
start.bat
tailscale serve --bg 4313
tailscale serve status
```

`status`에 표시되는 `https://<PC이름>.<tailnet>.ts.net` 주소가 폰에서 열 주소다. 이 주소는 내 tailnet 안에서만 열린다.

- **`tailscale funnel`은 쓰지 않는다.** 인터넷 전체에 공개되며, MemoReader는 Funnel 요청을 거부한다.
- 특정 계정만 허용하려면 설정 화면의 "허용할 Tailscale 계정"에 이메일을 넣는다. PC에서 직접(127.0.0.1) 여는 경우는 항상 허용된다.

## 3. 폰에서

1. 폰의 Tailscale을 켠 상태로 위 주소를 크롬(안드로이드)으로 연다.
2. 메뉴 → "홈 화면에 추가" / "앱 설치".
3. 설치 후 다른 앱의 **공유** 메뉴에 MemoReader가 나타난다 (안드로이드 크롬 기준).
   - iOS Safari는 공유 대상 등록(Web Share Target)을 지원하지 않는 것으로 알려져 있다. iPhone에서는 앱 안의 "저장" 탭에서 붙여넣거나 텔레그램 봇을 쓴다.

## 3-1. 밀린 메모 자동 동기화 켜기 (PC를 저녁에만 켜는 경우)

1. 폰에서 설치한 앱의 **설정 → 밀린 메모 자동 동기화 (알림) → 이 기기에서 알림 켜기**를 누르고 알림을 허용한다. (PC 서버에 닿아 있을 때 한 번만 하면 된다.)
2. 폰의 Tailscale은 **항상 켜 둔다**(안드로이드: Tailscale 앱의 상시 VPN 권장). 푸시는 폰을 깨우지만 PC까지의 연결은 Tailscale이 맡는다.
3. PC에서 `scripts\autostart-install.bat`을 실행하면 로그인할 때마다 서버가 자동으로 뜬다.
4. 이후 PC를 켜면: 15초 뒤 폰에 알림이 오고 → 앱이 닫혀 있어도 쌓인 메모가 PC로 올라가고 → PC가 정리를 마치면 한 번 더 알림이 와서 폰에 최종 정리본이 들어온다.

"테스트 알림 보내기"로 폰이 깨어나는지 미리 확인할 수 있다. 알림이 와도 PC에 연결하지 못했다면 알림에 "PC에 연결하지 못했어요"가 뜨고, 설정 화면의 "알림으로 깨어난 동기화 실패 원인"에 이유가 남는다. 앱을 열면 항상 그 자리에서 다시 동기화된다. 푸시가 오지 않는다면 폰의 배터리 최적화에서 크롬(또는 설치한 앱)을 제외한다.

## 4. 동작 방식

- 폰은 항상 자기 안(IndexedDB)에 먼저 저장한다. Tailscale이 꺼져 있거나 PC가 꺼져 있어도 저장·검색·열람은 된다.
- 연결되면 자동으로 동기화되고, PC가 정리한 결과(제목·요약·카테고리·태그)가 폰에 내려온다.
- 상단의 연결 표시: `PC 연결됨` / `오프라인 · 이 기기에 저장` / `연결 오류`. 누르면 즉시 동기화한다.

## 5. 문제 해결

| 증상 | 확인 |
|------|------|
| 폰에서 주소가 안 열림 | 폰 Tailscale 켜짐 여부, `tailscale serve status`, PC에서 `start.bat` 실행 여부 |
| 403 "접근이 허용되지 않았습니다" | 설정의 허용 계정 목록, 폰이 다른 Tailscale 계정인지 |
| "홈 화면에 추가"만 있고 설치가 안 됨 | HTTPS 인증서 켜짐 여부 (`https://` 주소로 열었는지) |
| 정리가 계속 "대기" | PC 설정 화면에서 LLM 제공업체 선택 후 "연결 테스트" |
