# 설치 가이드 (처음부터 끝까지)

Windows PC 한 대에 MemoReader 서버를 설치하고, Tailscale로 폰에서 접속하기까지의 전체 과정이다. 위에서부터 순서대로 따라 하면 된다. **PC만 쓸 거라면 1~5단계까지만** 하면 된다.

| 단계 | 내용 | 필요한 경우 |
|---|---|---|
| 1 | 준비물 설치 | 항상 |
| 2 | 코드 받기와 의존성 설치 | 항상 |
| 3 | 실행과 첫 화면 확인 | 항상 |
| 4 | 자동 정리(LLM) 연결 | 항상 |
| 5 | 로그온 시 자동 시작 | 권장 |
| 6 | Tailscale 설치와 폰 접속 | 폰에서 쓸 때 |
| 7 | 폰에 앱 설치와 알림 | 폰에서 쓸 때 |
| 8 | 텔레그램 봇 | 선택 |
| 9 | 로그인 쿠키 | 선택 |
| 10 | Obsidian 연동 | 선택 |

---

## 1. 준비물 설치

| 필요한 것 | 확인 방법 | 설치 |
|---|---|---|
| **Node.js 22 이상** | `node -v` 가 `v22` 이상 | https://nodejs.org 에서 LTS 설치 |
| **Git** | `git --version` | https://git-scm.com |
| **Chrome 또는 Edge** | 설치되어 있으면 됨 | 자바스크립트로만 보이는 페이지를 읽을 때 자동으로 사용한다. 설치 위치가 기본값이 아니면 `.env`에 `BROWSER_PATH=...` 로 알려 준다. |
| **LLM** (아래 중 하나) | 4단계에서 고름 | 설치된 CLI(`claude`, `codex`, `opencode`), 로컬 `ollama`, 또는 API 키(Anthropic, OpenAI, Gemini) |
| **Tailscale** (폰에서 쓸 때) | 6단계 | https://tailscale.com/download |

PowerShell 또는 명령 프롬프트를 열어 `node -v`, `git --version`이 나오는지 먼저 확인한다.

## 2. 코드 받기와 의존성 설치

```bat
cd C:\Claude
git clone https://github.com/madwind0526/MemoReader.git
cd MemoReader
npm install
```

- 설치 위치는 어디든 괜찮다. 이 문서는 `C:\Claude\MemoReader` 기준이다.
- 설정 파일을 따로 만들 필요는 없다. 포트(4313)와 저장 위치는 기본값이 있다. 바꾸고 싶을 때만 `.env.example`을 `.env`로 복사해 고친다.

## 3. 실행과 첫 화면 확인

```bat
start.bat
```

`start.bat`이 하는 일: 4313 포트를 쓰던 프로세스를 정리 → 앱 빌드 → 서버를 최소화된 창에서 실행.

1. "Done. Open http://127.0.0.1:4313" 이 보이면 아무 키나 눌러 창을 닫는다. (서버는 따로 떠 있는 `MemoReader` 창에서 계속 돈다.)
2. 브라우저에서 http://127.0.0.1:4313 을 연다.
3. 빈 보관함 화면이 보이면 성공이다.

| 명령 | 설명 |
|---|---|
| `start.bat` | 빌드 후 실행 (일반 사용) |
| `start.bat dev` | 개발 모드. API 자동 재시작 + 화면 핫 리로드 (http://127.0.0.1:5182) |
| `stop.bat` | 서버 종료 |
| `npm test` | 테스트 실행 |

> 서버는 보안상 `127.0.0.1`에서만 열린다. 같은 와이파이의 다른 기기에서는 열리지 않으며, 폰은 6단계의 Tailscale로 접속한다.

## 4. 자동 정리(LLM) 연결

메모를 저장하면 PC가 본문을 가져와 요약·태그·카테고리를 붙인다. 이 일을 할 LLM을 하나 연결해야 한다.

1. 화면 왼쪽(또는 메뉴)에서 **설정**을 연다.
2. **자동 정리 (LLM)** 에서 제공업체를 고른다.

   | 제공업체 | 필요한 것 |
   |---|---|
   | Claude CLI / Codex CLI / OpenCode CLI | 해당 CLI가 PC에 설치되어 로그인된 상태 |
   | Ollama | `ollama`가 실행 중 (기본 주소 `http://127.0.0.1:11434`) |
   | Anthropic / OpenAI / Gemini | API 키 입력 |

3. **연결 테스트**를 눌러 "연결되었습니다"가 나오는지 확인한다.
4. 저장한다.

- 선택한 방식이 실패하면 다음 제공업체로 자동 전환된다(순서는 설정 화면에 표시된다).
- 연결 전에 저장한 메모는 `정리 대기`로 남아 있다가, LLM을 연결하면 자동으로 정리된다.

테스트: 상단의 입력칸에 링크 하나를 붙여넣어 저장하고, 잠시 뒤 제목·요약·카테고리가 붙는지 본다.

## 5. 로그온 시 자동 시작 (권장)

PC를 저녁에만 켜는 경우, 켜자마자 서버가 떠서 밀린 메모를 정리하게 하려면 등록한다.

```bat
scripts\autostart-install.bat
```

- 관리자 권한은 필요 없다. 현재 사용자 로그온 30초 뒤에 `start.bat`이 실행된다 (작업 스케줄러에 `MemoReader` 작업이 생긴다).
- 해제는 `scripts\autostart-remove.bat`.
- PC를 켜면 서버가 대기 중이던 메모(정리 전, LLM이 없어 실패했던 것, 텔레그램에서 밀린 것)를 이어서 처리한다.

## 6. Tailscale 설치와 폰 접속

폰에서 MemoReader에 접속하는 방법은 **Tailscale** 하나뿐이다. 서버는 `127.0.0.1`에만 열려 있고, Tailscale이 내 기기끼리만 통하는 안전한 통로와 로그인 신원(계정)을 제공한다. 별도 비밀번호는 없다.

### 6-1. Tailscale 설치 (PC와 폰, 한 번만)

1. **PC**: https://tailscale.com/download 에서 Windows용을 설치하고 로그인한다. 작업 표시줄에 Tailscale 아이콘이 생기면 된다.
2. **폰**: Play 스토어/App Store에서 **Tailscale**을 설치하고 **PC와 같은 계정**으로 로그인한다. VPN 연결 허용을 누른다.
3. PC와 폰의 Tailscale이 모두 "Connected"인지 확인한다.

### 6-2. 관리 콘솔 설정 (한 번만)

https://login.tailscale.com/admin/dns 에서 다음 두 가지를 켠다.

1. **MagicDNS**: 켜기
2. **HTTPS Certificates**: 켜기 (Enable HTTPS)

HTTPS가 켜져 있어야 폰에서 앱 설치(PWA)와 공유 메뉴 등록이 된다.

### 6-3. 서버를 Tailscale에 연결 (PC)

`start.bat`으로 서버를 띄운 상태에서:

```bat
tailscale serve --bg 4313
tailscale serve status
```

`status`에 `https://<PC이름>.<tailnet이름>.ts.net` 형태의 주소가 나온다. **이 주소가 폰에서 열 주소**다. 이 설정은 PC를 다시 켜도 유지된다.

> **`tailscale funnel`은 쓰지 않는다.** 인터넷 전체에 공개하는 기능이며 MemoReader는 요청을 거부한다. `tailscale serve`만 사용한다.

### 6-4. 폰에서 접속 확인

1. 폰의 Tailscale을 켠다.
2. 폰 크롬(안드로이드)에서 위 `https://...ts.net` 주소를 연다.
3. 보관함이 보이고 상단에 `PC 연결됨`이 표시되면 성공이다.

### 6-5. 특정 계정만 허용하고 싶다면 (선택)

PC에서 **설정 → 접근 허용 → 허용할 Tailscale 계정**에 이메일을 넣고 저장한다. 비워 두면 내 tailnet의 기기는 모두 접속할 수 있다. PC에서 직접(127.0.0.1) 여는 경우는 항상 허용된다.

## 7. 폰에 앱 설치와 알림

### 7-1. 홈 화면에 앱으로 설치

1. 폰 크롬에서 위 주소를 연다.
2. 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**.
3. 설치 후에는 홈 화면의 아이콘으로 연다. 다른 앱의 **공유** 메뉴에 MemoReader가 나타나, 링크·글을 바로 보낼 수 있다 (안드로이드 크롬 기준).

> iPhone은 공유 메뉴 등록(Web Share Target)이 지원되지 않는다. 앱 안의 **저장** 탭에 붙여넣거나 텔레그램 봇(8단계)을 쓴다.

### 7-2. 밀린 메모 자동 동기화 (PC를 저녁에만 켜는 경우)

1. 폰에서 설치한 앱의 **설정 → 밀린 메모 자동 동기화 (알림) → 이 기기에서 알림 켜기**를 누르고 알림을 허용한다. (PC 서버에 연결된 상태에서 한 번만.)
2. 폰의 Tailscale은 **항상 켜 둔다**. 안드로이드는 Tailscale 앱의 상시 VPN 설정을 권장한다.
3. **테스트 알림 보내기**로 폰이 깨어나는지 확인한다.
4. 이후 PC를 켜면 이런 순서로 동작한다.
   - 15초 뒤 폰에 알림이 온다.
   - 앱이 닫혀 있어도 쌓인 메모가 PC로 올라간다.
   - PC가 정리를 마치면 한 번 더 알림이 와서 폰에 정리된 결과가 들어온다.

알림이 오지 않으면 폰의 배터리 최적화에서 크롬(또는 설치한 앱)을 제외한다.

### 7-3. 세 가지 사용 방식

- **폰 단독**: 폰은 항상 자기 안에 먼저 저장한다. PC나 Tailscale이 꺼져 있어도 저장·검색·열람은 된다.
- **PC 단독**: PC 브라우저만으로도 동작한다. 링크 본문 수집과 LLM 정리는 PC가 한다.
- **연동**: 연결되면 자동으로 동기화되고, PC가 정리한 결과(제목·요약·카테고리·태그)가 폰에 내려온다.

## 8. 텔레그램 봇 (선택)

링크를 텔레그램으로 보내 저장하는 통로다.

1. 텔레그램에서 **@BotFather**에게 `/newbot`을 보내 봇을 만들고 **토큰**을 받는다.
2. MemoReader **설정 → 텔레그램 봇**에서 사용을 켜고 토큰을 붙여넣는다. 저장한다.
3. 텔레그램에서 만든 봇에게 `/id`를 보낸다. 봇이 **채팅 ID**를 알려 준다.
4. 설정의 **허용할 채팅 ID**에 그 숫자를 넣고 저장한다. 허용되지 않은 채팅은 저장되지 않는다.
5. 봇에게 링크나 글을 보내면 저장된다. `/list`로 최근 저장 목록을 볼 수 있다.

## 9. 로그인 쿠키 (선택)

페이스북·인스타그램처럼 로그인해야 보이는 글을 읽고 싶을 때 쓴다. 기본은 꺼져 있다.

1. PC 브라우저에서 해당 사이트에 로그인한다.
2. "Get cookies.txt LOCALLY" 같은 확장 프로그램으로 **cookies.txt**(Netscape 형식)를 내보낸다.
3. **설정 → 로그인 쿠키 (선택) → 쿠키 파일 선택**으로 파일을 올린다. 파일은 이 PC의 `data` 폴더에만 저장되고 저장소에는 올라가지 않는다.
4. 평소 정리에서는 로그인 없이 읽다가, 본문이 너무 짧을 때만 쿠키가 저장된 사이트에 한해 한 번 더 읽는다. 같은 사이트의 페이지 사이에는 10~16초 간격을 둔다.
5. 모든 정리에서 항상 쿠키를 쓰고 싶으면 "브라우저로 읽을 때 로그인 쿠키 사용"을 켠다. (계정이 봇으로 의심받을 수 있어 권하지 않는다.)

## 10. Obsidian 연동 (선택)

저장 폴더가 그대로 Obsidian 보관소다. 자세한 내용은 [obsidian.md](obsidian.md).

1. Obsidian → **폴더를 보관소로 열기** → `C:\Claude\MemoReader\data\vault_output` 선택.
2. 위치를 바꾸려면 `.env`에 `VAULT_DIR=D:\내\보관소\MemoReader` 를 적고 `stop.bat` → `start.bat`.

## 문제 해결

| 증상 | 확인 |
|---|---|
| `start.bat` 후 바로 창이 닫힘 | 최신 `start.bat`은 끝에 `pause`가 있다. `git pull`로 갱신 후 다시 실행 |
| `Build failed.` | 같은 창에 나온 오류를 확인. 보통 `npm install`을 안 했거나 Node가 22 미만 |
| 포트가 이미 사용 중 | `stop.bat` 실행 후 `start.bat`. 다른 프로그램이 4313을 쓰면 `.env`의 `PORT`를 바꾼다 |
| 폰에서 주소가 안 열림 | 폰 Tailscale 켜짐, PC에서 `tailscale serve status`, PC에서 `start.bat` 실행 여부 |
| 403 "접근이 허용되지 않았습니다" | 설정의 허용 계정 목록, 폰이 다른 Tailscale 계정인지 |
| "홈 화면에 추가"만 있고 앱 설치가 안 됨 | `https://` 주소로 열었는지, HTTPS Certificates가 켜졌는지 |
| 정리가 계속 "정리 대기" | 설정에서 LLM 선택 후 **연결 테스트** |
| 본문이 안 읽히는 페이지 | Chrome/Edge 설치 여부, 필요하면 9단계 로그인 쿠키 |
| 화면이 바로 갱신되지 않음 | 새로고침. 폰은 Tailscale이 켜져 있는지, 상단 연결 표시가 `PC 연결됨`인지 |

업데이트할 때는 다음 순서로 한다.

```bat
stop.bat
git pull
npm install
start.bat
```

`data` 폴더(메모·설정·쿠키)는 업데이트로 지워지지 않는다. 백업은 `data\vault_output` 폴더를 복사해 두면 된다.
